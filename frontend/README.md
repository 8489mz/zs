# zsystems react frontend

واجهة React + TypeScript حديثة للنظام، مبنية على feature-based architecture مع React Router وTanStack Query وZustand.

## التشغيل
```bash
npm ci
npm run dev
```

## البناء
```bash
npm run build
```

## فحوص الواجهة
```bash
npm run qa
```

## التحقق من نسخة الواجهة المنشورة (بعد كل نشر)
- معرّف البناء `__APP_BUILD_ID__` هو الـ commit المنشور (git short SHA)، ويظهر في صفحة مبيعات الفان وفي رابط الـ service worker (`/sw.js?v=<sha>`) — قارنه مع الـ HEAD المنشور قبل الحكم على أي إصلاح.
- تحديث قوي (Ctrl+F5) لا يمسح Cache Storage ولا يُسقِط الـ service worker القديم: جرّب دائماً على ملف تعريف نظيف أو نافذة تصفح خفي، أو ألغِ تسجيل الـ service worker وامسح بيانات الموقع (Application → Clear site data) ثم أعد التحميل.
- بانر التحديث يظهر فقط عند وجود worker جديد بانتظار التفعيل، ولا يفرض نفسه أبداً أثناء الوردية — التفعيل يتم فقط بضغطة المستخدم على «تحديث الآن».
